## Overview

The Wild Oasis Website is a modern booking platform for luxury cabins in the Italian Dolomites. Built with Next.js and Supabase, it offers a seamless user experience with real-time availability updates, secure authentication, and responsive design.

---

## Features

- **Next.js App Router**: For optimized performance and SEO
- **Supabase Backend**: Real-time database and authentication
- **Tailwind CSS**: Utility-first styling framework
- **Responsive Design**: Works on all device sizes
- **Jest Testing**: Comprehensive test coverage
- **Modern UI**: Clean, intuitive interface

## Getting Started

### Prerequisites

- Node.js v18+
- npm v9+
- Git

### Installation

```bash
git clone https://github.com/AhmeedDahy/The-Wild-Oasis-Website.git
cd The-Wild-Oasis-Website
npm install
```
